# Siev Minh Personal Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Run the website

1. Extract the folder.
2. Open `index.html` in your browser.

You can also use the VS Code Live Server extension.

## Customize

### Personal photo
Replace the `profile-placeholder` section in `index.html` with:

```html
<img src="assets/profile.jpg" alt="Siev Minh">
```

Then add your image to the `assets` folder.

### CV
Place your CV in:

`assets/Siev-Minh-CV.pdf`

### Contact details
Replace these placeholders in `index.html`:

- `your-email@example.com`
- GitHub profile URL
- LinkedIn profile URL

### Project links
Replace the sample GitHub and live-demo URLs in the Projects section.

## Contact form

The current form displays a browser message only. Connect it to EmailJS,
Formspree, or your own backend to receive real messages.
