# Siev Minh Portfolio — React JavaScript Rebuild

This project recreates the same portfolio design using a simpler frontend stack:

- Vite
- React
- JavaScript (JSX)
- Tailwind CSS
- Lucide React

It intentionally removes Next.js, TypeScript, Framer Motion, `next/image`, and `next-themes` while preserving the visual design and interactions.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
